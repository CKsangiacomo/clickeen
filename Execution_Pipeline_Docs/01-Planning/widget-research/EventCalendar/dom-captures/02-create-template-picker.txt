--- TEMPLATE VARIETY: STRUCTURAL, NOT JUST CONTENT ---

Names alone imply distinct layouts, confirmed by thumbnails:
  Movie Show Schedule            month grid
  Weekly School Schedule         week grid
  Upcoming Events Sidebar Widget narrow vertical column
  Slider Exhibition              carousel
  Festival Lineup / Club Events  hero / poster styling
  University Events List         dense list
  Team Games Schedule            row list with per-row emphasis

This confirms the rule recorded in WidgetCompetitorResearchSteps.md 3.4:
template variety tracks layout capability. Calculator exposes no layout axis and
its 116 templates vary only by content. Event Calendar exposes many layouts and
its 18 templates vary structurally.

--- EVENT ITEM MODEL, read from the Team Games Schedule preview ---

Each event row renders:
  date badge          "AUG 1"  (month abbrev + day, stacked)
  image               team logo, circular
  category/tag        "AWAY" / "HOME", uppercase, above the title
  title               "vs.Astros"
  time range          "3:00 PM - 5:00 PM"  with a clock icon
  location            "AT&T Park – San Francisco Giants"  with a pin icon
  per-event CTA       "Get Tickets" button, right-aligned
  row emphasis        HOME rows render dark navy, AWAY rows light grey

So a single event carries at minimum: date, start time, end time, title,
category, location, image, and its own CTA — plus a per-event visual emphasis
state. That is a materially richer item than any current Clickeen widget item.
