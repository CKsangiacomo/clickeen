# Prague Migration From Astro Blocks To Page Composer

Status: **CANCELLED — HISTORICAL PLANNING ONLY**

Decision date: 2026-08-06

Prague will not migrate to the deferred Clickeen Pages product.

Prague is a complex, dynamic, global marketing site with automation and
site-level behavior beyond the intended scope of simple Clickeen Pages. It
continues on its existing Astro architecture, which remains the authority for
Prague routes, navigation, layouts, market behavior, content automation, build,
and deployment.

Clickeen Widgets may continue to appear inside Prague through their normal
published Widget Instance URLs. Prague does not become a Page Builder consumer,
and future Prague improvements must be planned against Prague's actual runtime
rather than against PRD 127.

The earlier migration proposal is cancelled. Git history preserves its prior
content; agents must not execute or reconstruct it.
